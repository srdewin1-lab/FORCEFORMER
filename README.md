# My studio · My condition

Build from the warm-lit A platform to the blue-lit B platform in Godot 4.7.2. Paint and stack GridMap tiles, reshape objects from the pieces folder, and replace Condition.json with your Force Former condition. Keep the complete project in this same repository through the remaining sprints; Save for GitHub saves your scenes and explains the GitHub Desktop handoff.

[Course Guide](https://interactive-media-game-studio.netlify.app/condition-kit.html#godot-guide)
